# تست وکالت

سایت استاتیک سوالات چندگزینه‌ای برای کنکور وکالت. روی GitHub Pages یا Cloudflare Pages بدون سرور کار می‌کند.

## انتشار روی Cloudflare Pages

1. این پوشه را به یک ریپوی گیت‌هاب پوش کنید.
2. در Cloudflare Pages همان ریپو را وصل کنید.
3. Build command خالی بگذارید، Output directory را `/` بگذارید.

یا GitHub Pages: Settings → Pages → Deploy from branch → root.

## افزودن درس جدید بدون دردسر کد

دو راه:

### راه سریع داخل خود سایت
فایل اکسل را از باکس بالای صفحه انتخاب کنید. همان لحظه مواد و تست ساخته می‌شود. این حالت فقط روی مرورگر شماست و ذخیره دائمی ندارد.

### راه دائمی برای گیت‌هاب
1. از `data/آیین-دادرسی-مدنی.xlsx` کپی بگیرید.
2. برگه «سوالات» را پر کنید. ستون‌های مهم:
   - `question`, `A`, `B`, `C`, `D`, `answer` (حرف A/B/C/D)
   - `explain`, `laws`
   - `article` مثل `ماده ۱۹ ق.آ.د.م`
   - `article_title`
   - `difficulty`: آسان / متوسط / سخت
   - `similar_group` برای سوالات شبیه هم
3. تبدیل به JSON:

```bash
python3 tools/excel_to_json.py data/تجارت.xlsx tejarat "حقوق تجارت" data/tejarat.json
```

4. در `data/lessons.json` فیلد `ready` را `true` و `count` را بگذارید.

سوالات و گزینه‌ها از فایل اصلی دست‌نخورده مانده‌اند. فقط ستون دسته‌بندی اضافه شده.

## رفتار تست
- کلیک روی ماده → تعداد سوال و شروع
- هر سوال ۶۰ ثانیه
- انتخاب زودتر یا اتمام زمان → گزینه صحیح، درست/غلط، پاسخنامه و متن قانون همان صفحه
- ترتیب داخل هر ماده: سخت → متوسط → آسان
